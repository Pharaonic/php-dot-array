# Support

## Documentation

The full documentation is on [pharaonic.dev](https://pharaonic.dev/packages/php/dot-array). Its source is in [`docs/sections`](docs/sections). Read [UPGRADE.md](UPGRADE.md) before upgrading from 2.x.

## Questions and help

- Ask on the [Pharaonic Discord community](https://discord.gg/XQG9RhvEvf).
- Search the [existing issues](https://github.com/Pharaonic/php-dot-array/issues) first; your question may already be answered.

## Bugs and feature requests

Open an issue with the [bug report](https://github.com/Pharaonic/php-dot-array/issues/new?template=bug_report.yml) or [feature request](https://github.com/Pharaonic/php-dot-array/issues/new?template=feature_request.yml) template. For a bug, include the array, the path, what you expected and what you got.

## Security

Do not report security vulnerabilities through public issues. See [SECURITY.md](SECURITY.md).
